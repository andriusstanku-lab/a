# Instrukcija - PU7 .odb failai

## Atidarymas

1. Atsisiųskite LibreOffice: https://www.libreoffice.org/download/
2. Atsisiųskite .odb failus iš GitHub:
   - DB1.odb - DB6.odb (visi turi tą patį turinį - 18 dep, 18 supp, 51 inv)
3. Dukart spustelėkite ant kiekvieno
4. Vartotojo vardas: `SA`, slaptažodis tuščias

## Ekrano nuotraukoms

- **Tools - Relationships** (rodo 1:N ryšius)
- **tblInventory** lentelę (Datasheet View)
- **Tools - Query Wizard** užklausoms kurti

## Pastaba

Visi 5 .odb failai (DB1-DB6) turi tą pačią lentelių struktūrą iš originalių .accdb. 
Užklausos (qry*), formos (frm*) ir ataskaitos (rpt*) iš originalų MS Access turi būti 
sukurtos LibreOffice Base aplinkoje, kaip aprašyta dokumente. SQL ekvivalentai 
pateikti 1 priede.
